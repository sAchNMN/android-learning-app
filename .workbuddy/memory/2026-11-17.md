# 2026-11-17

## 登录"网络连接失败"排查结论

**账号密码**：`admin` / `admin123`（若依超管，`docs/api.md` 已记录）。curl 直连 `POST /login` 返回 200 + token，凭据没问题。

**两个独立坑，都踩了：**

1. **装的是旧 APK**。`./gradlew assembleDebug` 只编译不安装，模拟器上还跑着之前用
   `-PapiBaseUrl=http://127.0.0.1:8080/` 打的包。必须 `adb install -r` 才生效。
   → 验证手段：看界面底部"接口地址"，或读 `app/build/generated/source/buildConfig/debug/.../BuildConfig.java` 里的 `BASE_URL`。

2. **`10.0.2.2:8080` 从 App 里连不上**（OkHttp `SocketTimeoutException: failed to connect ... after 15000ms`），
   但宿主机 `curl 127.0.0.1:8080` 正常、后端确实在 `0.0.0.0:8080` LISTENING。
   注意设备 shell 里 `toybox nc -w 3 10.0.2.2 8080` 报 PORT_OK **是假阳性**，别拿它当结论。
   怀疑 Windows 防火墙拦入站（未取证，未动防火墙）。

**可用方案（已验证）**：`adb reverse tcp:8080 tcp:8080` + 用 `127.0.0.1` 打包。
- 这条规则能跨 Bash 调用存活（adb server 是常驻 daemon），但 adb server 重启/模拟器重启后要重来。
- 完整流程必须一条命令跑完：install → reverse → am start → 输入 → 截图。

```
./gradlew assembleDebug -PapiBaseUrl=http://127.0.0.1:8080/
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb reverse tcp:8080 tcp:8080
```

**结果**：登录 → 200 → GET /getInfo 带 Bearer token → 进入"点外卖"首页，3 家店正常加载。

## adb 输入踩坑（比 MEMORY.md 里记的更细）

- Gboard 中文（拼）模式下 `input text` 会被拼音合成吃掉，只剩首字母。
  `ime set ...LatinIME en_US` 传子类型**不生效**（不报错但没切换）。
- Gboard 联想条会盖住密码框，`input tap` 点密码框实际点到联想条，
  "admin" 被自动补成 "administrator"。教训：**输入完先截图确认再进下一步**。
- 可行路径：点账号框 → `input text admin` → `input keyevent 61`（TAB 跳下一格）→
  `input text admin123` → `input keyevent 111`（ESC 收键盘，不能用 BACK 4，会退到桌面）→ 点登录。
- 登录按钮坐标：1280x2856 屏，(636, 1810)。

## 已落地改动（改默认值 + adb reverse 进构建）

`android/app/build.gradle.kts`：
- debug 默认 `BASE_URL` 由 `http://10.0.2.2:8080/` 改为 **`http://127.0.0.1:8080/`**
- 新增 `backendPort` 属性（默认 8080，`-PbackendPort=` 可覆盖）
- 新增 `resolveAdb()`：`-PadbPath` → `ANDROID_HOME`/`ANDROID_SDK_ROOT` → `local.properties` 的

- `tasks.matching { it.name == "installDebug" }.configureEach { dependsOn(adbReverse) }`
  → **`./gradlew :app:installDebug` 一条命令完成「建隧道 + 装包」**
