## 首页下线 + 推荐页接真音源 + 跨音源喜欢同步

结构：底部导航从「首页/播放/推荐/本地/我的」改为 **播放/推荐/本地/我的**，默认落推荐页
（`MainActivity.DEFAULT_TAB = 1`）。首页 `HomeFragment/HomeAdapter` 与 8 个相关资源已删。

客户端新增：

- `FavoritesStore` 从「只存 key」改为存完整 `MusicTrack`（Gson，JSON 落 SharedPreferences）；
  旧的 `keys` StringSet 只读兼容，升级不丢收藏。**原因**：推荐页收藏的是在线曲目，
  不在本地/云端曲库里，只存 key 还原不出标题/封面/酷狗 hash。
- `RecommendCacheStore`：推荐结果本地缓存，断网回放 + 标记离线。
- `DeviceIdStore`：UUID 当用户身份（App 无登录体系）。
- `MusicViewModel`：`recommend/loadRecommendations/tasteArtists/syncLibrary/playTracks`。
  `playTracks` 会并行预解析前 5 首在线曲目的播放地址再整队播放（否则「播放全部」只能播一首）。
- `RecommendFragment` 重做：hero + 为你推荐（每行红心）+ 来自音源歌单 + 本机歌单；
  歌手榜、假排行榜删除（本地洗牌不是推荐）。

服务端新增（`server/business/music`）：

- `RecommendService`：种子歌手聚合搜索 → 补 `personalized/newsong` → 去重 + 排除已喜欢 → 按 seed 洗牌
- `MusicUserService` + `biz_music_user_like`：先写后端再推平台，`saved` 与 `syncs` 分开返回
- `MusicSourceProvider` 加 4 个 default 方法（dailyRecommend/like/myPlaylists/playlistTracks），
  只有网易云覆写；酷狗留「暂不支持」，不假装成功
- 接口：`/app/music/recommend|like|likes|playlists|playlist`，用 `deviceId` 归属，全部 @Anonymous
