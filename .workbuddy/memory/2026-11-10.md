## 贪吃蛇小游戏（当天实现）

- 两个源文件：`SnakeRules.kt`（纯 Kotlin 规则，零 Android 依赖，可单测）+ `SnakeGameView.kt`（自定义 View：Canvas 绘制 + 滑动/轻点输入 + Handler 定时步进）。
- 规则要点：20 列固定、行数 = 高度/格子边长（棋盘铺满不留白）；撞墙不穿墙；不吃食物时尾格不算碰撞、吃食物时全身判定；反向与重复输入丢弃，转向最多排队 2 个。
- 节奏：初始 180ms/步，每吃 4 个加速 10ms，下限 80ms。
- `MainActivity` 用 SharedPreferences（`snake_prefs` / `best_score`）存最高分。
- 单测 `app/src/test/java/.../SnakeRulesTest.kt` 8 条全过（开局长 3、移动不掉长、吃食加分增长、撞墙死、咬到自己死、反向输入被拒、双向快速转向排队、死后不再移动）。
- 布局踩坑：`setOnApplyWindowInsetsListener` 里 `setPadding(left, top, right, bottom)` 会**覆盖** XML 的 `paddingHorizontal`，导致文字贴边。解法：root 只吃 insets，内层 LinearLayout 再放 16dp 内边距。
- 截图证据：`.workbuddy/shots/`（README 待开始 / 运行中 / 结算界面）。

## 改版：全屏 + 悬浮信息 + 蛇头靠近淡出

- 布局只剩 `FrameLayout` + `SnakeGameView` match_parent，删掉分数行、提示行、重新开始按钮（重开靠轻点）。
- **关键取舍**：棋盘底色 `drawRect(0,0,width,height)` 铺满含系统栏；但**可玩网格让开系统栏**（`originY = insetTop + 居中余量`，`rows = (h - insetTop - insetBottom) / cell`）。否则食物会生成在状态栏图标下面，玩家看不见也吃不到（实测第一版就是这样）。
- `setContentInsets(top,bottom)` 由 Activity 的 insets listener 注入；insets 到达比 onSizeChanged 晚，所以几何计算统一收敛到 `updateGeometry(w,h)`，两处都调，几何变了就重建 `SnakeRules` 回到 READY。
- 悬浮胶囊：Canvas 画的圆角 pill（底色 `#2BFFFFFF` 玻璃感），得分左上 / 最高右上 / 操作提示底部居中（**仅 READY 显示**，开局后自动隐藏）。
- 淡出算法：蛇头格中心到胶囊矩形的最近距离，换算成格数，`1.1 格内全透明 → 3.4 格外不透明`，线性映射；每帧向目标值缓动 0.2，未收敛时 `postInvalidateOnAnimation()` 自续帧，收敛即停（不常驻 60fps）。
- 绘制顺序踩坑：胶囊原先画在遮罩之前，暂停/结算时被 dim 压暗。现顺序为 棋盘→食物→蛇→遮罩→胶囊。
- 配色调整：网格 `#1FFFFFFF`（原 `#14FFFFFF` 太淡看不见）；READY 遮罩降到 `0x66` 否则棋盘黑成一片、蛇的预览完全消失。
- 截图证据：`12/15/17/18`（首屏、运行、结算、最终），`14_fade_near.png` 是淡出实证（左上得分几乎消失、右上最高保持不透明）。

### 后端选型：官方 RuoYi-Vue（不是 yudao）

| 项 | 官方 RuoYi-Vue | yudao（ruoyi-vue-pro） |
| --- | --- | --- |
| 成功码 | `code == 200` | `code == 0` |
| 登录路径 | `POST /login` | `/admin-api/system/auth/login` 或 `/app-api/member/auth/login` |
| token 位置 | 响应**顶层** `token` | `data.accessToken` |

官方若依的三条硬约束（Android 端已按此实现）：
1. 成功判定 `code == 200`
2. header `Authorization: Bearer <token>`，前缀不能省
3. **未登录返回 HTTP 200 + body code=401**，只看 HTTP 状态码会漏判

**若依没有 C 端用户体系**，只有 `sys_user`（后台账号）。课设直接用可跑通；正式项目建议加 `biz_app_user` 表 + 复用 `TokenService` 签 token（SQL 已备好）。
